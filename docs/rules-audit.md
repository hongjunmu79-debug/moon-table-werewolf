# 规则校验与本桌约定

本项目供语音房法官辅助主持，采用公开基础教学中常见的规则。不同赛事、平台和板型存在差异；这里记录实际实现，避免把可选约定称为唯一标准。

| 项目 | 实现与默认值 | 变体与边界 |
| --- | --- | --- |
| 胜负 | 新建推荐局均屠边；好人消灭全部狼人，狼人消灭全部村民或全部神职 | 自选可选人数制；旧房间保留原胜负约定 |
| 女巫自救 | 默认仅首夜可自救 | 可选全程可自救、全程不能自救；须有解药且只能救狼刀目标，并非所有专业比赛均准许首夜自救 |
| 夜间用药 | 每夜最多一瓶；解药用完不再显示刀口 | 不能毒自己；毒杀猎人不能开枪 |
| 守卫 | 可自守，不可连守，同守同救出局，毒药不受守护影响 | 空守后可再次守之前的目标 |
| 狼刀 | 允许自刀或选择狼队成员；唯一最高票生效 | 平票或全部弃票为空刀 |
| 警长 | 9–12 人可选；竞选在首夜死亡公布前完成 | 首夜被刀者在公告前仍可上警、投警长票和自爆 |
| 警长选举 | 仅最初不上警者投票；退水不恢复投票权；平票 PK 后一次加投，再平票无警长 | PK 不可退水；法官提前结束阶段时未操作按放弃处理 |
| 警徽与归票 | 放逐 1.5 票；警长定方向、最后发言；出局或白痴翻牌可移交或撕徽 | 可移交给尚未翻牌的存活玩家；法官仅在明确选择或离线时辅助操作 |
| 狼人自爆 | 存活普通狼人可在白天普通发言、放逐 PK、警长竞选发言、选方向时自爆 | 不能在夜间、报名、投票、猎人技能、警徽处理时自爆；不带走额外玩家 |
| 警上吞徽 | 默认单爆吞警徽，本局不再选警长 | 双爆可选：首爆结算夜间死亡后暂停，次日保留原上警与退水记录续选；第二次吞徽 |
| 自爆衔接 | 公开自爆者身份、出局并跳过放逐；警上先公布当夜死亡、处理猎人和警徽 | 法官在自爆处理页确认下一夜；遗言在语音房按开局约定执行 |
| 放逐 PK | 先单独 PK 发言，再台下加投；台上无投票权；再次平票无人出局 | PK 期间可自爆，加投开始后不可自爆 |
| 换座 | 发牌前可退座重入、选空位、双方确认互换 | 稳定会话不随换位转移；双方取消准备；未决换位阻止发牌；开局后禁止 |

## 结算范围

本桌采用夜间死亡统一公布、先处理可触发的猎人技能再判断胜负的约定。目前没有提供某些赛事的“狼刀在先”胜负优先级选项，也不包含白狼王、狼王等特殊角色。6–11 人推荐配置是朋友局建议，不宣称统一赛事板型。遗言、语音发言和禁言由法官在原语音房执行。

## 参考来源

- [官方基础玩法：胜负、女巫、警长票权](https://langrensha.com/wanfa/guize/2017/10/18/26899_719311.html)：该板型女巫不能自救，说明首夜自救并非全平台统一规定。
- [女巫自救的三种规则](https://www.langrensha.net/strategy/2022121302.html)：按建房约定提供首夜、全程可救、全程不可救。
- [法官主持与警长、守卫规则](https://www.langrensha.net/strategy/2021050801.html)：报名时序、原警下投票、PK、警徽和同守同救。
- [狼人自爆时机](https://www.langrensha.net/strategy/2020111901.html)：白天发言自爆，投票等阶段限制。
- [自爆与吞警徽的不同约定](https://www.langrensha.net/strategy/2022082901.html)：普通自爆不带人，警上吞徽按板型选择。

## 验证

`npm test` 覆盖身份隔离、规则校验、旧房间兼容、三种自救、守卫、白痴、警长选举及 PK、1.5 票、警徽、猎人、自爆、换位同意与过期操作。真实 HTTP 会话脚本 `tests/http-sheriff.mjs` 和 `tests/http-seats-explosion.mjs` 验证多人服务端响应与流程；`tests/http.mjs`、`tests/http-larger.mjs` 验证原完整牌局与大小桌回归。
