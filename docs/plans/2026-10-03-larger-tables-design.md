# 6–12 人语音局扩展

目标：同一房间分享与独立浏览器席位流程支持 10、11、12 名玩家，法官另计。建房时选择推荐或自选，发牌前允许法官修改，所有人重新准备确认。

推荐配置沿用小桌旧规则；大桌提供经典预女猎白和预女猎守配比，使用屠边规则。自选允许调整角色数量、屠边/人数制和女巫首夜自救。角色总数必须与人数相等，狼人少于好人，至少一名村民、一名神职，特殊角色各不超过一名。

守卫阶段加入夜间状态机，仍对其他席位隐藏具体阶段与目标；禁止连守，空守会打断连守；守护和解药同时命中狼刀目标会使其死亡，守护不能挡毒。白痴首次被放逐后公开身份，保留存活和发言，但从投票者、放逐候选中移除。

旧数据库房间没有配置字段时，按旧小桌配置与人数制读取。重开保留配置但重置角色技能和私密记录。修改配置增加 epoch 并取消所有准备，旧请求拒绝。配置数量公开，分配结果仍只对本人、狼队和法官按权限提供。

验收覆盖所有人数和板型发牌、非法配置、权限与旧请求、守卫/女巫结算、白痴投票限制、两种胜负、旧房间及重开。真实 HTTP 测试使用各自独立 Cookie 的 10–12 名玩家，并验证前端建房、配置编辑及移动布局。部署到既有服务后重复关键 HTTP 验证。
