# 月下 · 狼人杀

给已有语音房使用的网页主持工具。支持 6–12 位玩家和一名不参与游戏的法官：分享房间链接、入座、私密发身份、夜间行动、白天投票与复盘。语音仍由你们原来的语音房提供。

## 推荐玩法与自选玩法

- 新建 6–12 人推荐配置统一使用屠边规则：狼人全灭则好人胜；神职或村民任一类全部出局则狼人胜。旧房间保留已有配置。
- 10 人经典推荐为 3 狼、4 民、预言家、女巫、猎人；11 人经典推荐为 3 狼、4 民、预言家、女巫、猎人、白痴；12 人经典推荐为 4 狼、4 民、预言家、女巫、猎人、白痴。
- 10–12 人也可选择守卫局：以守卫替换第四神职，10 人时增加守卫并减少一位村民。上述大桌推荐使用屠边胜负规则。
- 自选支持狼人、村民以及预言家、女巫、猎人、白痴、守卫。各神职最多一位；人数总和必须匹配。可选择屠边或人数制。女巫默认仅首夜可自救，另可选择全程可自救或全程不能自救；每夜最多一瓶药，解药用完后不再显示狼刀。
- 9–12 人可开启警长：先报名和竞选，再公布首夜死亡；原警下玩家投票，退水者不能投警长票。平票 PK 加投一次，PK 不能退水，再平票则无警长。警长放逐票权为 1.5，可选发言方向并最后归票，出局或白痴翻牌后移交或撕徽。
- 普通狼人可在白天发言、放逐 PK、警长竞选发言或选择发言方向时自爆；夜间、报名、投票与猎人技能阶段禁止。自爆公开身份、出局、跳过放逐，法官处理死亡技能和警徽后推进下一夜。警上默认单爆吞警徽，也可选双爆：首爆暂停并保留原上警和退水记录，次日续选，第二次吞徽。
- 开局前可选择空座位、取消入座后重入、移到空位，或由双方确认互换。申请换位会取消双方准备；有待处理申请时不能发牌。开局后禁止换位或取消入座。
- 法官可在发牌前修改本桌玩法，保存后全员重新准备。重开保留配置，重新随机发牌。

推荐配置不等于完整比赛规则。女巫自救、警上自爆存在不同板型约定，建房前应确认。守卫可自守、不可连守，同守同救仍出局，毒药不受守护影响。白痴首次被放逐时公开翻牌并保留发言权，此后不能投票或再被放逐，其他致死方式仍生效。放逐平票先 PK 发言再加投，台上玩家不能投票。夜间信息只在授权席位的服务端响应中提供。规则来源、所选变体和结算限制见 [规则校验](docs/rules-audit.md)。

仓库仅包含应用源码，不包含正在使用的房间数据、云环境配置、域名或服务端密钥。复制本项目的人需要部署到**自己的**云环境；使用此仓库不会获得原部署环境的访问权限。

## 本地运行

需要 Node.js 22 或更高版本。

```bash
npm ci
npm run typecheck
npm test
npm run build
```

本地测试可以设置 `TEST_MEMORY_DB=1` 后执行 `npm start`，使用内存房间数据。这个模式仅供测试：进程重启会丢失房间，正式部署绝不可启用。

## 部署到腾讯云 CloudBase

1. 创建自己的 CloudBase 环境和文档型云数据库集合 `moon_rooms`。集合的客户端安全规则应禁止直接访问；网页只通过本项目的服务端 `/api/room` 读写。
2. 在云托管中部署根目录的 `Dockerfile`，服务端口设为 `8080`。设置环境变量 `TCB_ENV` 为**你自己的**环境 ID。
3. 为云托管服务配置仅在服务端使用的 CloudBase API Key，通过云托管环境变量 `CLOUDBASE_APIKEY` 注入。该密钥具有敏感权限，**不要写进源码、Git 提交、构建文件或前端环境变量**。按腾讯云控制台的安全设置限制其使用范围，并定期轮换。
4. 开启服务公网访问后，检查 `/healthz`，再用两个独立浏览器验证建房、入座和身份隔离。

免费体验套餐与云托管均有用量和计费限制，部署前请在控制台核对套餐、超限按量开关及告警。腾讯云默认域名仅适合开发测试；正式公开服务应使用符合平台要求的自有域名。

## 当前限制

- 房间在创建 24 小时后停止访问，但项目目前没有自动删除过期数据库记录的任务。持续运营前应配置清理策略。
- 前台页面约每 2.5 秒查询一次房间状态，后台页面暂停轮询；人数或房间数增加仍会提高数据库与云托管用量。面向公众开放前，应进一步优化刷新频率并增加建房限流。
- 房间链接只用于邀请；法官和玩家权限依赖各自浏览器中的私密会话 Cookie。不要在共享设备上使用重要牌局。
